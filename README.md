# 🛰️ satellite-nav-quiz

> 卫星导航课程复习答题系统 — 201道选择题 · 20章 + 补充题库 · 日系动漫清新风格

[![GitHub Pages](https://img.shields.io/badge/GitHub_Pages-deploy-ready-brightgreen)](https://pages.github.com)
[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

## ✨ 特性

- 📚 **20个章节** — 完全对齐教材，每章含 🌱基础 + 🌿进阶 + 🌳挑战 三级难度（161题）
- 📖 **补充题库** — 40题深入内容，覆盖接收机结构、信号处理算法、电离层模型等
- 📋 **考试大纲模式** — 按考纲重点智能组卷，支持自主选择知识点和难度
- ✅ **自动评分** — 实时计算正确率与得分
- 🔍 **薄弱环节分析** — 根据答题数据智能分析薄弱知识点
- 📝 **智能错题本** — 自动收录易错题，支持针对性复习
- 🎵 **背景音乐** — 内置 BGM，可开关和调节音量
- 📱 **手机适配** — 响应式设计 + 移动端底部导航栏
- 💾 **本地存储** — 进度保存在浏览器，无需登录
- 🎨 **日系动漫风格** — 粉色渐变 · 圆角卡片 · 浮动装饰


## 📁 项目结构
